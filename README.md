## Key improvements over the Perplexity draft
1. **Triangulation / Estimation Agent:** fills data gaps the way consultants do, instead of handing them back to humans.
2. **Automation that can be audited:** automation rate *plus* a weekly audit with a severity-weighted error budget (≥98% numbers / ≥95% qualitative), with automatic threshold tightening.
3. **Living Fact Base + Country Source Registry:** knowledge compounds across MTI's 760+ assignments in 56 countries.
4. **Validation cascade + cross-family verification:** cheaper and less biased than running every check on every claim.
5. **Staged budget with ROI**, with a worked example and output mock-ups as evidence (concept only, no build).
