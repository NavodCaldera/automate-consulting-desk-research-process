## Key improvements over the Perplexity draft
1. **Triangulation / Estimation Agent:** fills data gaps the way consultants do, instead of handing them back to humans.
2. **Automation that can be audited:** automation rate *plus* weekly audited precision (≥98%), with automatic threshold tightening.
3. **Living Fact Base + Country Source Registry:** knowledge compounds across MTI's projects in 51 countries.
4. **Validation cascade + cross-family verification:** cheaper and less biased than running every check on every claim.
5. **Staged budget with ROI**, plus a working prototype and red-team demo as evidence.
